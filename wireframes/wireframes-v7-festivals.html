Design notes

  • Month cards: each Gregorian month is a rounded card; header shows month + count.
  • Per-festival icons: distinct icon chip per festival (palette = Holi, crown = Janmashtami, etc.).
  • Named ekadashis: shown in both tabs — tagged EKADASI in the Festivals list.
  • Ekadasi tab: date-only chips, all 24/year, no paksha or tithi labels.
  • Fix: all ekadashis now reach the Ekadasi tab (named ones were previously dropped).
