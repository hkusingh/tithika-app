Section 2 — Design notes

Why no separate Yoga timeline?

Yoga changes roughly once per day (~every 24 hours), so there is no need for a multi-row timeline like Karana or Choghadiya. A single "current + next" two-row card is sufficient. The progress bar fills the role that a timeline would fill for a faster-changing element.

Karana vs Choghadiya — why list all karanas even if they span into tomorrow?

Each karana is ~12 hours long. A sunrise-to-next-sunrise day typically overlaps with 4 karanas. Showing all 4 gives the user a complete picture of what's coming. Rows that extend past midnight use a "+1" suffix on the end time — same convention already used on the Hora screen.

Nav icon choice

The current nav bar right side has 4 icons (festivals, month, hora/muhurta, settings). Adding a 5th requires either (a) making the icons slightly smaller, or (b) moving one feature behind a long-press / secondary sheet. Recommended: use ⊕ (circled plus — evokes "the five additions") at the same size, or replace the ☆ (hora/muhurta bookmark) with a menu that opens a bottom sheet listing Hora, Muhurta, and Panchanga. Open question for UX review.

Day View — zero changes needed

Option C means the Day View is untouched. Yoga and Karana are only visible when the user deliberately navigates to the Panchanga screen. This is the right trade-off if the primary user need is "quick daily overview" rather than "deep panchanga consultation".
