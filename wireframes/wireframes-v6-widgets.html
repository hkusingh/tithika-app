4 — Design Notes

Constraints, rendering approach, and data strategy for native implementation.

Moon Phase Rendering

  • Terminator ellipse algorithm: terminatorRx = r · cos(litFraction · π)
  • Shukla (1–15): right side lit; Krishna (16–30): left side lit
  • Positive terminatorRx → crescent (dark ellipse overlaid on lit semicircle)
  • Negative terminatorRx → gibbous (lit ellipse extends into dark semicircle)
  • iOS: replicate painter in SwiftUI Canvas or UIBezierPath in widget extension
  • Android: Glance Canvas or custom RemoteViews with Bitmap pre-rendered by app

Data Bridge Strategy

  • App writes a JSON snapshot to shared App Group storage on every open and notification schedule
  • JSON keys: tithi, tithiNum, paksha, nakshatra, sunriseUtc, sunsetUtc, rahuStart, rahuEnd, festival, tzId, generatedAt
  • Widget extensions read JSON — no ephemeris calls from widget target
  • If JSON is stale (>26 h), widget shows last-known data with faded opacity

Rahu Kaal Bar Math

  • Bar represents sunrise→sunset window (100% width)
  • Bar fill left = (rahuStart − sunrise) / (sunset − sunrise)
  • Bar fill width = (rahuEnd − rahuStart) / (sunset − sunrise) ≈ 1/8 ≈ 12.5%
  • Active state: current time within [rahuStart, rahuEnd]; tick at (now − sunrise) / (sunset − sunrise)
  • Active: border turns red, fill goes solid, NOW badge shown

Update Cadence

  • iOS WidgetKit: hourly TimelineEntry slots, midnight boundary for next-day refresh
  • iOS Timeline invalidated on app open via WidgetCenter.shared.reloadAllTimelines()
  • Android Glance: WorkManager periodic task every 30 min; also refresh on app open
  • Active Rahu window: OS may not reload mid-hour; widget shows "active" based on system time at render

Tap Targets

  • Small widget: entire widget taps to Day View (Routes.dayView via App Intent)
  • Medium widget: tap anywhere opens Day View; no sub-element routing in v1
  • Lock screen widgets: tap opens app at Day View (standard accessory widget behavior)
  • Android: single Intent deep-link to Day View activity

Lock Screen Vibrancy

  • iOS accessory widgets use system vibrancy — no custom color palette
  • In SwiftUI: apply .widgetAccentable() to accent-colored elements
  • Moon phase in circular widget: white fill on dark, dark fill on light — system handles tint
  • Text always uses system primary label color; secondary uses .secondary foreground style

Implementation Packages

  • iOS: native WidgetKit extension (Swift + SwiftUI) — home_widget does not support WidgetKit
  • Android: home_widget: ^4.x with Glance AppWidgetReceiver (Kotlin)
  • Shared App Group: group.com.tithika.app (iOS) / shared SharedPreferences (Android)
  • Moon phase Bitmap for Android: pre-rendered by Flutter layer into shared storage, read by widget

Color Tokens (exact hex)

  • Dark bg: #0B0F1E · Shukla gold: #E6B85C · Krishna blue: #7B8EE8
  • Light bg: #F5F0E8 · Shukla gold: #C8922A · Krishna blue: #5A6BD8
  • Rahu warn dark: #D46060 · light: #B84040
  • Festival orange dark: #E07840 · light: #C05A1A
